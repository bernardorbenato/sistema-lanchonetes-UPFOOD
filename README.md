# UPFOOD

Aplicação web desenvolvida como projeto acadêmico para gerenciamento e realização de pedidos em lanchonetes.

## Sobre o projeto

O UPFOOD é uma aplicação inspirada em plataformas de pedidos de comida. O projeto foi desenvolvido para aplicar conhecimentos de desenvolvimento web, organização de interfaces e lógica de programação.

A aplicação possui funcionalidades voltadas para clientes e para a administração das lanchonetes.

## Funcionalidades

### Área do cliente

- Visualização de estabelecimentos
- Visualização de cardápios
- Seleção de produtos
- Carrinho de compras
- Processo de pagamento
- Confirmação de pedidos
- Histórico de pedidos

### Área administrativa

- Dashboard administrativo
- Gerenciamento de clientes
- Gerenciamento de produtos
- Gerenciamento de pedidos
- Relatórios
- Gerenciamento das informações dos estabelecimentos

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/bernardorbenato/sistema-lanchonetes-UPFOOD.git
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.

A versão atual não exige instalação de dependências adicionais.

Projeto desenvolvido durante a formação acadêmica em Engenharia de Software, com foco na aplicação prática de conceitos de desenvolvimento web e construção de sistemas.
