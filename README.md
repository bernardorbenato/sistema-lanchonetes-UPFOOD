projeto feito para a matéria de experiência de usuário em conjunto com a matéria prototipagem de sistemas. 
A UPfood é um webcommerce inspirado no ifood para estudantes universitários que não tem tempo para esperarem em uma fila no intervalo entre as aulas.
o sistema possui login acadêmico e login administrativo, com as funções de favoritos, comprados anteriormente, lojas, separação pro bloco e restaurantes, cadastro de produtos e gerenciamento de lojas e etc.

o sistema foi produzido com o auxilio das IA´S do claude e do chatgpt. Utilizando HTML, CSS e Javascript.
